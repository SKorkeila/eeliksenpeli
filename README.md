# 🦤 Dodon saari 🔥

Selainpeli, jossa dodo-lintu juoksee saarella ja väistelee tulivuoren tulipalloja.

## Pelaaminen

Avaa `index.html` selaimessa – asennuksia ei tarvita.

- **Hyppää:** välilyönti, nuoli ylös tai klikkaa / napauta
- **Äänet päälle/pois:** M tai 🔊-kuvake
- **Kilpi 🛡️:** nappaa hyppäämällä – suojaa yhdeltä tulipallolta

## Tehty vaiheittain

1. Hahmo hyppää
2. Esteet ja törmäys
3. Pisteet ja kiihtyvä vauhti
4. Oma ulkoasu ja teema
5. Ennätys, äänet ja tehostin
6. Jakaminen kavereille
